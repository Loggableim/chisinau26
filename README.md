# Chișinău 26 – Reiseplan

Responsive Low-Budget-Reiseplanung für zwei Personen:

**Varna → Constanța → Tulcea → Galați → Chișinău**

## Features
- Deutsch / Ukrainisch Umschalter
- Aktuelle Route und bereits gebuchte Unterkünfte
- Low-Budget-Empfehlungen
- Mobil- und Desktop-Ansicht
- Automatisches GitHub-Pages-Deployment über GitHub Actions

## GitHub Pages
Unter **Settings → Pages → Build and deployment** als Source **GitHub Actions** auswählen.

Danach wird die Seite über den Workflow `.github/workflows/pages.yml` veröffentlicht.

Voraussichtliche URL:

`https://loggableim.github.io/chisinau26/`
